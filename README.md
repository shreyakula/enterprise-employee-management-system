# Enterprise Employee Management System

A Java-based Employee Management System designed to streamline HR operations, employee record management, payroll tracking, and reporting through a secure and scalable platform.

## Overview

This project was developed as part of a Software Development course and simulates a real-world enterprise employee management solution. The system supports both HR administrators and employees through role-based access, allowing secure management of employee information and payroll data.

## Features

### Authentication & Authorization
- Secure login system
- Role-based access control
- HR Administrator and Employee user roles

### Employee Management
- Add new employee records
- Search employees by:
  - Employee ID
  - Name
  - Date of Birth
  - SSN
- Update employee information
- Delete employee records

### Payroll Management
- View employee payroll history
- Salary adjustment functionality
- Percentage-based salary increase processing

### Reporting
- Employee pay statement history
- Monthly payroll totals by division
- Monthly payroll totals by job title
- New hire reports within a selected date range

### Database Design
- MySQL relational database
- Normalized schema design (3NF)
- Foreign key relationships
- Secure data organization and retrieval
